# Security Policy

## Supported versions

Only the latest commit on the `main` branch receives security fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report it privately through GitHub: open the **Security** tab of this repository and click **Report a vulnerability**. You will get a first response within 7 days, and a fix or mitigation plan will be shared with you before any public disclosure.

Please include:

- The affected part (smart contract, frontend, or CI)
- The network and contract address, if the issue was found on a deployed contract
- Steps to reproduce, and a proof of concept if you have one

Smart contracts hold real funds once deployed to a public network, so contract findings are treated with the highest priority.
